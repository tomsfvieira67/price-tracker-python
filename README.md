# 🛒 E-Commerce Price Tracker (Web Scraper)

A Python-based web scraper designed to extract product information (such as title, price, and stock availability) from e-commerce websites. This project demonstrates how to navigate HTML structures and automate data extraction.

## 🚀 Technologies Used
* **Python 3**
* **`requests`** (for handling HTTP requests and spoofing User-Agents)
* **`beautifulsoup4`** (for parsing HTML and finding DOM elements)

## ⚙️ How to Run Locally

1. **Clone this repository:**
   ```bash
   git clone [https://github.com/tomsfvieira67/price-tracker-python.git](https://github.com/tomsfvieira67/price-tracker-python.git)

2. **Navigate to the project directory:**
    ```bash
    cd price-tracker-python

3. **Install the required dependencies:**
    ```bash
    pip install requests beautifulsoup4

4. **Run the scraper:**
    ```bash
    python scraper.py

*Note: This script currently targets books.toscrape.com (a sandbox environment for web scraping) for educational and training purposes.*
